# Merchants Yard website preview

[Open the website](https://frompaulxam-gif.github.io/merchants-yard-winter/)

[Private Hire](https://frompaulxam-gif.github.io/merchants-yard-winter/private-hire/)

A proposed winter website with genuine venue still photography, separate menus, events, booking links and private hire. Preview only; this repository does not operate the current venue domain. Generated static files, with no customer records or raw footage.

Design follows the Moonshine A layout, adapted with Merchants Yard colours, pill buttons, photo cards, separate pages and subtle optional snowfall.

Signup opens the existing official form. Private-hire enquiries compose an email for the visitor to send. Fonts currently follow the existing public website while supplied brand files are pending.
